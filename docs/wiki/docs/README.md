
# ShyBossBar

ShyBossBar is a powerful and flexible BossBar plugin designed for Bukkit and Folia-based Minecraft servers. It allows server administrators to create custom boss bars that can be displayed to players based on permissions, commands, or WorldGuard regions.

## Features

* **Multiple BossBar Types** - Create unlimited custom boss bars with different activation methods
* **Flexible Display Options** - Activate boss bars through permissions, commands, or WorldGuard region flags
* **Server Compatibility** - Full support for both Bukkit and Folia server implementations
* **PlaceholderAPI Integration** - Use dynamic placeholders in your boss bar messages
* **WorldGuard Integration** - Display boss bars when players enter specific regions
* **Asynchronous Processing** - Runs efficiently without impacting server performance
* **Wide Version Support** - Compatible with Minecraft versions 1.9.R1 through 1.21.R6
